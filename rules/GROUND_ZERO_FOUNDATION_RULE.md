# Ground-Zero Foundation Rule (v59)

This is a terrain/context rule, not a project-only rule.

Use it when a large procedural build will be placed on unknown terrain, uneven terrain, steep terrain, or intentionally floating placement.

## Rule

Create a visible artificial base datum under the build:

- floor/deck grid,
- perimeter skirt,
- underside supports,
- edge thickness,
- access points,
- clean pedestrian clearance above.

## Why

V11 megacity screenshots showed that a dense ground layer on unknown terrain can still read as floating or chaotic. V12 corrected this with a ground-zero platform so the base can be placed in the air and still photograph as a built megastructure.

## Scope control

This rule should transfer to future projects with the same terrain problem. It should not be forced onto builds where terrain integration is the point, such as organic ruins, gardens, or grounded landmark recreations.
