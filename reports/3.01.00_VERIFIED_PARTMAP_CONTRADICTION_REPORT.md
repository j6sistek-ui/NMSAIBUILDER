# 3.01.00 Verified Part Map Contradiction Report

## Scope

Compared the verified Builder-spawn extraction overlay against the active 3.00.00 part map/rules. This report distinguishes true contradictions from diagnostic caveats.

## Overall result

No universal placement rule was invalidated. The recipe-first model remains correct: recipes control assemblies; the part map/verified overlay controls component mechanics.

## Confirmed contradictions / replacements

| ObjectID | Existing source assumption | Verified data result | Action |
|---|---|---|---|
| `CUBEWALL_SPACE` | Mapped like `CUBEWALL` with valid dimensions/spacing. | Spawns invisible/zero-bbox. | Mark `DO_NOT_USE`; do not use for generated builds. |
| `BASE_FLORAL03` | Mapped to `BASE_FLORAL01` extents. | Spawned/measured geometry differs, but user visual review says placement is OK. | Mark as decorative proxy/variant mismatch; bbox conflict diagnostic only. |
| `TELEPORTER` | Mapped to `TELEPORTER_F` expected extents. | Spawned teleporter extents differ across all variants. | Mark `REVIEW_EXTENT_MISMATCH`; use with caution and prefer verified spawn data. |
| `FRE_FACE_WALL` | Mapped to `FRE_FACE_WINDOW` extents. | Zero-bbox in Builder spawn extraction. | Review before use. |
| `FRE_ROOM_IND1` | Mapped to `FRE_ROOM_IND` extents. | Zero-bbox in Builder spawn extraction. | Review before use. |
| `PIPE` | Mapped to `BASE_BUBPIPE` extents. | Zero-bbox in Builder spawn extraction. | Review before use; prefer other pipe ObjectIDs unless specifically validated. |

## Non-contradictions

- Sixteen `B_STR_AA*` Corvette/hull/plating rows have verified spawned dimensions but no expected extents in the old library. This is incomplete prior data, not a failed placement rule.
- Twenty-six active source-library rows were not present in the extraction input library; they are flagged `NOT_EXTRACTED_FROM_INPUT_LIBRARY`, not marked invalid.
- Decorative flora/coral/grass/proxy-like bbox conflicts do not automatically indicate bad placement. Use in-game context or group trend evidence when visual footprint matters.

## Rule updates made

- Added `rules/VERIFIED_PARTMAP_DATA_PROTOCOL.md/json`.
- Added verified map files under `library/`.
- Added `data/PARTMAP_VERIFIED_EXCEPTION_INDEX.json`.
- Updated active part library rows with verified extraction fields.
- Updated placement map/status rows with verified statuses and exception policy.
- Updated `PART_PLACEMENT_AID_LEDGER` to cite verified overlay and exception policy.

## Practical effect

Future builds can check verified spawn/origin/rotation/scale/bbox data before relying on old FBX-derived assumptions.
